# Code of Conduct

OEE Workspace follows the [Open Engineering Education Code of Conduct](https://github.com/0xbuffdev/open-engineering-education/blob/main/governance/CODE_OF_CONDUCT.md), which is maintained as the canonical copy in the OEE repository.

Report unacceptable behavior to the community leaders responsible for enforcement at christohybrid185@gmail.com. The linked document defines the expected behavior, its scope, and how reports are handled.
