# Security policy

## Scope

OEE Workspace provides templates, generation scripts, and documentation for learner workspaces. It uses no runtime services, and its security surface is its automation and content integrity: the generation scripts, GitHub workflows, and the guidance the templates give learners.

## Reporting

Report suspected vulnerabilities or trust violations to oee@0xbuff.com.

Trust violations include:

- Malicious or tampered scripts and GitHub workflows.
- Guidance that encourages unsafe, unauthorized, or unlawful activity.
- Impersonation of maintainers or of the OEE project.

Include the affected file or workflow, the repository revision, and the steps to reproduce. Do not open a public issue for an unresolved security problem. The maintainers coordinate disclosure after a fix or an assessment.

## Supported versions

Security fixes are applied to `main`.
